# massCode Community Themes

Official community theme registry for [massCode](https://github.com/massCodeIO/massCode).

Browse and install any theme directly inside massCode via **Settings → Appearance → Community Themes**.

## Contributing a Theme

See [CONTRIBUTING.md](./CONTRIBUTING.md) for the theme format, validation rules, and pull request checklist.

## Registry Format

`registry.json` is auto-generated by GitHub Actions whenever changes in `themes/` are merged into `main`. Do not edit `registry.json` manually.
